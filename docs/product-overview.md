# VoStory 产品概述

## 定位

VoStory 是一个自用的 AI 有声小说 / 广播剧制作工具。

它的目标不是简单地把文本转成语音，而是把长篇小说转化为可编辑、可返工的广播剧工程：小说结构化为脚本，每个角色有固定的基础音色，每句台词按场景语境演绎，最后拼接导出。

核心价值：

- 将小说自动结构化为制作脚本
- 自动识别、合并角色，泛称角色归入路人池
- 为角色自动设计固定的基础音色，并按场景生成语气
- 支持批量生成与局部返工

## 需要解决的核心问题

- 从长篇小说中抽取人物，处理别名、称呼和重复角色
- 上千个角色时控制需要配音的角色数量（合并去重 + 路人池）
- 识别对白、旁白和内心独白，给台词归属正确的说话人
- 保证角色声音在整本书中的一致性（固定参考音频 + 固定随机种子）
- 同一角色在不同场景下有不同的语气、语速和情绪（演绎指令）
- 长篇内容分批处理，支持断点续跑、批量生成和局部重生成
- 多音字、专有名词的读音纠正（发音词典）

## 形态

`Web 前端 + Go 服务端 + LLM / Breeze-TTS-2 服务`，部署在自己的机器上使用。

服务化而不是桌面端，主要是为了：

- 长任务（章节切分、批量配音）放在后台队列里跑，浏览器关掉也不中断
- TTS 模型跑在 GPU 机器上，可以和 Web 服务分开部署
- 角色、音色、发音词典可以跨项目复用

## 完整流程

1. 导入一本小说，自动分章
2. LLM 逐章切分脚本，识别说话人、情绪和演绎指令
3. 合并重复角色，泛称角色归入路人池
4. 为主要角色和路人池自动生成基础音色
5. 按章节批量生成音频
6. 只对有问题的句子修改演绎指令或文本后重生成
7. 导出章节音频

## 命名

`VoStory`，来自 `Voice + Story`。
